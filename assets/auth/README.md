# Authentication artwork

`google-g.png` is the unmodified Google G from
https://developers.google.com/static/identity/images/g-logo.png,
downloaded 2026-10-05 for the Google sign-in button.

Use it according to https://developers.google.com/identity/branding-guidelines.
Do not recolor or redraw the Google symbol. The PlayWorship logo continues to
use `assets/pwLogoSinFondo.png`; Apple renders its own native authorization button.
