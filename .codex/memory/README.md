# Codex memory

This directory stores repository-specific context that should be loaded at the
start of future Codex conversations.

Files:

- `project-memory.md`: durable project context and decisions.
- `startup-checklist.md`: what to inspect before editing and how to validate.
- `skill-routing.md`: when to use specialized skills or workflows.
- `lessons-learned.md`: accumulated lessons from previous tasks.

Rules:

- Keep facts stable and actionable.
- Remove outdated guidance instead of accumulating conflicting notes.
- Prefer links to canonical files over copying large sections.
- If a memory conflicts with `AGENT.md`, `AGENT.md` wins.
- When a task teaches something reusable, write it down before finishing.
