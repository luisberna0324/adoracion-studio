💡 Cómo funciona

El motor de audio de MTControls procesa hasta 64 stems en tiempo real usando el pipeline de JUCE. Cada stem pasa por un ResamplingPositionableSource → StemBufferingSource con read-ahead de 262,144 samples. El StemMixEngine combina todas las pistas y aplica TimeStretchProcessor para pitch/tempo shifting con compensación de latencia mediante SimpleDelayLine. El StemOutputRouter enruta cada stem a canales de salida específicos (1-2, 3-4, etc.). El sistema de crossfade permite transiciones suaves de 2.5 segundos entre canciones usando dos instancias de StemMixEngine.

Sample Rate: 44.1 kHz
Block Size: 512
Stems: 4/64
