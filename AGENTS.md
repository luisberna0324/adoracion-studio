# AGENTS.md

Usar `docs/okf/` como fuente de datos y comportamiento técnico del proyecto.
Consultar el módulo relevante antes de modificar transporte, arrange, motor de
audio, mixer, MIDI o sistemas de audio, y actualizar la documentación cuando
esos contratos cambien.

Al preparar una subida/release, usar la skill `playworship-release-notes` si esta
disponible (copia versionada en `.agents/skills/playworship-release-notes/`) y
consultar `docs/okf/release/ReleaseNotes.md`. Las notas editoriales
y la disponibilidad se mantienen en archivos separados; su preparacion no
autoriza publicar, mover tags ni ejecutar Actions.
